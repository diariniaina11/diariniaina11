### AutoProspection

**React • Laravel • N8N • Supabase**

An outbound prospecting platform that uses cold emailing
method. Anticipating all possible responses increases the
chances of gaining clients with automation and AI agent.

### BlogAuto

**WordPress • N8N • MySQL**

Automation of blog creation and complete article publishing using n8n combined with WordPress. Generation, verification, and publication of articles every 2 days.

### Stock

**Angular • Spring Boot • PostgreSQL**

A stock management web application using the FIFO (First In, First Out) 
method. Angular was used for the user interface, AdminLTE to enhance 
the visual appeal—especially for the dashboard—and Spring Boot and 
PostgreSQL for the REST APIs and database.
